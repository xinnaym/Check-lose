# Покерный клуб «Чек это проигрыш» ♠️♥️♦️♣️

Веб-приложение и турнирный Live-Таймер покерного клуба **«Чек это проигрыш»** (спортивный Техасский Холдем, дружеские турниры на фишки и очки клубного рейтинга).

---

## 🔐 Учётная запись Дилера (Пульт дилера)

Учётная запись дилера преднастроена прямо в локальной базе данных (`data/club-db.json`). Обычная регистрация на сайте создаёт учётные записи **только в роли Игрока** (`role: "player"`).

Для входа в **«Пульт дилера»** (или через окно «Войти» в шапке сайта) используйте данные:

- **Логин (или Email):** `dealer` *(или `dealer@checkclub.ru`)*
- **Пароль:** `dealer25000`
- **Роль в БД:** `dealer` (Главный Дилер)

> **Требования к паролям:** минимальная длина пароля при регистрации игроков — **6 символов**.

---

## 🗄 Локальная база данных (без облака)

Проект полностью работает на **локальной файловой базе данных** без внешних облачных подключений:

- **Файл базы данных:** `data/club-db.json`
- **Репозиторий работы с БД:** `src/db/repository.ts`
- Все изменения (регистрация игроков, запись за турнирные столы, очки рейтинга, штрафы, бан-лист, уровни блайндов и история турниров) автоматически сохраняются на диск в `data/club-db.json`.
- При статическом деплое (например, на **GitHub Pages**) приложение автоматически использует локальное хранилище браузера (`localStorage`) с той же преднастроенной учётной записью дилера (`dealer` / `dealer25000`).

## 🚀 Запуск проекта локально

1. **Установка зависимостей:**
   ```bash
   npm install
   ```

2. **Запуск сервера разработки (Backend + Live WebSocket + Frontend):**
   ```bash
   npm run dev
   ```
   В консоль будет выведен локальный адрес сайта:
   - `http://localhost:3000/`

3. **Сборка фронтенда (для продакшена или GitHub Pages):**
   ```bash
   npm run build
   ```

## ⚙️ Основные возможности

- **Анонс & Запись за стол:** зарегистрированные игроки могут записываться за открытые турнирные столы (1 или 2 стола) и отменять запись в один клик.
- **Live-Таймер:** синхронизированные через WebSocket часы уровня, блайнды, анте, рассадка игроков по столам и местам (без отображения карт), протокол выбывания и активные штрафы.
- **Сезонный Рейтинг:** таблица лидеров сезона, зона Топ-10 Финального стола и индикация заблокированных участников (`БАН`).
- **Пульт дилера (только по авторизации дилера):**
  - Управление таймером и уровнями блайндов (`Старт`, `Пауза`, `+1 мин`, переключение уровней);
  - Поиск игроков по **имени, фамилии и никнейму** во всех списках;
  - Выбывание игроков с автоматическим начислением очков (Шаблон A / Шаблон B) и возврат (`Отмена`);
  - Назначение штрафов за столом (`-500 фишек`, `Бан 5 мин`, `-1000 фишек`, `Дисквалификация + Бан в клубе`);
  - Управление клубным бан-листом участников с указанием причины блокировки.
